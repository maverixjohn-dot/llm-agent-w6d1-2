# LLM Agent W6D1_2

GUI-агент на tkinter для параллельного сравнения ответов LLM с разными
параметрами и стратегиями промптинга. Основан на `deepseek_agent day5 v3.py`;
в версии **W6D1_2** добавлена поддержка локальной модели через
OpenAI-совместимый сервер (LM Studio).

**Файл:** `deepseek_agent W6D1_2.py`

## Провайдеры

| Провайдер | Модели | Ключ |
|---|---|---|
| DeepSeek API | `deepseek-v4-flash`, `deepseek-v4-pro` | `DEEPSEEK_API_KEY` |
| GigaChat API | `GigaChat-3-Ultra` | `GIGACHAT_CREDENTIALS` |
| Локальная (LM Studio) | `qwen3.8-27b` | не требуется |

## Требования

- Python 3.10+ (используется синтаксис `dict | dict`)
- `pip install requests`
- tkinter (входит в стандартную поставку Python для Windows)
- Для локальной модели: запущенный LM Studio с загруженной моделью
  `qwen3.8-27b` и включённым сервером на порту 1234

## Запуск

```bash
python "deepseek_agent W6D1_2.py"
```

## Переменные окружения

| Переменная | Назначение | Умолчание |
|---|---|---|
| `DEEPSEEK_API_KEY` | ключ DeepSeek (обязательна для моделей DeepSeek) | — |
| `GIGACHAT_CREDENTIALS` | Base64-ключ авторизации GigaChat | — |
| `GIGACHAT_SCOPE` | scope OAuth GigaChat | `GIGACHAT_API_PERS` |
| `GIGACHAT_VERIFY_SSL` | `"true"`, если установлен корневой сертификат НУЦ Минцифры; иначе проверка SSL отключена | выкл |
| `GIGACHAT_API_URL` / `GIGACHAT_AUTH_URL` | переопределение endpoint'ов GigaChat | см. код |
| `GIGACHAT_TIMEOUT` | таймаут чтения ответа GigaChat, сек | `300` |
| `LOCAL_API_URL` | endpoint локального сервера | `http://127.0.0.1:1234/v1/chat/completions` |
| `LOCAL_MODEL` | ID локальной модели (как в LM Studio) | `qwen3.8-27b` |
| `LOCAL_TIMEOUT` | таймаут чтения ответа локальной модели, сек | `600` |

Пример (Git Bash / Linux):

```bash
export DEEPSEEK_API_KEY="sk-..."
export GIGACHAT_CREDENTIALS="..."
python "deepseek_agent W6D1_2.py"
```

## Возможности

- **До 4 параллельных наборов параметров** — каждый набор выполняется в своём
  потоке и даёт отдельный ответ во вкладке результатов.
- **Стратегии ответа** (включают промежуточные вызовы модели):
  - *Прямой ответ* — один запрос;
  - *Ответ с инструкцией* — пользовательская инструкция добавляется в системный промпт;
  - *Предварительный промпт* — модель сначала генерирует оптимальный промпт, затем отвечает на него;
  - *Группа экспертов* — несколько ролей отвечают независимо, затем модератор синтезирует итог.
- **Параметры по провайдерам:**
  - DeepSeek: thinking mode + reasoning effort (low/high/max) либо температура; формат ответа text/json_object;
  - GigaChat: температура, top_p, штраф повторов, reasoning effort (low/medium/high);
  - Локальная: температура, формат ответа text/json_object.
- **Метрики на каждый ответ**: время, токены (prompt/completion), стоимость
  (DeepSeek — в $ с учётом кэша; GigaChat freemium и локальная — 0 ₽).
- **Сводная таблица** всех запусков с копированием строк в буфер обмена.
- Буфер обмена: ПКМ-меню и Ctrl+V/C во всех полях ввода, «Вставить из буфера»
  для задачи, «Копировать всё» для результатов.

## Примечания

- У GigaChat freemium генерация идёт в одном потоке: несколько параллельных
  наборов с GigaChat получат HTTP 429.
- Для локальной модели убедитесь, что значение `LOCAL_MODEL` совпадает с ID
  модели в LM Studio (`GET /v1/models`). Имя по умолчанию — `qwen3.8-27b`.
- При `json_object` для DeepSeek и локальной модели в системный промпт
  автоматически добавляется подсказка «Ответь строго в формате JSON».
